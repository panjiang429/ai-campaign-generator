# 作品 02 · 一键 Campaign 生成器

AI 应用作品集 · 作品 02 · 作者：江盼（香港城市大学 BISMIS）

**技术主线：一份结构化输入 → 多种形态的产出。** 规则模板引擎与大模型双通道，同一份 Brief 按不同目标平台的硬规则派生出结构各异的成品。

## 这是什么

填一份 Campaign Brief，按平台规则自动产出差异化内容包：小红书图文笔记、抖音口播脚本 + 分镜、微博话题文案、公众号推文大纲、视频号短口播，并配好配图 / 分镜提示词与 T-7 到 T+3 的发布排期。同一份卖点，五个平台各自的字数、语气、话题格式、画面逻辑都不同——不是一套文案复制五遍。

## 怎么跑

单文件应用：直接双击 `index.html`，或推到 GitHub 仓库开启 Pages 后用链接访问。无需安装、无后端、无外部依赖。

## 核心逻辑

1. **平台规则库**：内置各平台的内容结构（小红书 300-500 字 + 3 标题、抖音前 3 秒钩子 + 5 秒一变、微博 140 字 + 双话题、公众号五段大纲、视频号 20 秒口播）；
2. **模板引擎**：默认离线可跑，标题与卖点轮换组合，语气（理性专业 / 亲和真诚 / 年轻潮流）影响措辞；
3. **大模型模式**：右上角配置接口后，由模型按同一 Brief 重写全部平台内容（JSON 结构化返回），输出标注来源；
4. **预算结构建议**：按预算档给内容制作 / 达人 / 投流的分配比例。

## 数据声明

页面预填的「澄野 CENYO」为虚构示例产品，仅作演示。全部计算在浏览器本地完成；接入大模型时密钥只存在本机 localStorage。
